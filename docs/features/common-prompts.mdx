OpenYiDA is designed to understand natural language. The prompts below are proven patterns that work well across all supported AI tools (Claude Code, Cursor, Wukong, etc.).

---

## App Creation

```
Build me a [xxx] application
```
```
Help me set up a CRM
```
```
Create a personal salary calculator app
```
```
Build me an IPD system on Yida to manage the full chip production workflow
```
```
Generate an app from this requirements document: [paste your PRD here]
```
```
Create a birthday greeting mini-game on Yida
```
```
Build a Lantern Festival riddle guessing game
```

## Form & Page Operations

### Create a form page

```
Help me create a [xxx] form page
```
```
Create a leave request form with fields: employee name, department, start date, end date, reason
```

### Add fields to a form

```
Add a [field name] field to [page name], field type: [text / number / date / dropdown / ...]
```
```
Add a "Department" dropdown field to the Employee Info form, options: Engineering, Marketing, Sales, HR
```

### Modify field properties

```
Make the [field name] field on [page name] required
```
```
Set the [field name] field on [page name] to read-only
```
```
Change the label of [field name] on [page name] to [new label]
```

### Custom display pages

```
Create a custom display page for [page name]
```
```
Generate an enterprise collaboration product landing page
```
