# OpenYiDA Docs

Official documentation for [OpenYiDA](https://github.com/openyida/openyida), powered by [Mintlify](https://mintlify.com).

**Live site:** https://docs.openyida.ai

## Development

Install the [Mintlify CLI](https://www.npmjs.com/package/mintlify) to preview locally:

```bash
npm install -g mintlify
mintlify dev
```

Open http://localhost:3000 to view the docs.

## Deployment

This repository is connected to Mintlify. Every push to `main` triggers an automatic deployment to https://docs.openyida.ai.

To improve the docs, open a PR against this repository. See the [Contributing Guide](https://docs.openyida.ai/docs/contributing) for details.
